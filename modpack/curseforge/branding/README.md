# Pack branding

- **`Project_Island_logo.png`** — included in **`curseforgeModpackZip`** under **`branding/`** in the zip.
- **CurseForge project thumbnail:** uploading or importing the pack zip **does not** attach this image to the project—set it manually once under **Edit project → Images / Logo**. Use a **square** image **≥ 400×400** px if the site asks for logo specs.
